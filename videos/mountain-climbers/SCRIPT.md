# SCRIPT — mountain-climbers

**Voice:** es_AR-daniela-high (piper, español rioplatense)
**Voice direction:** Coach claro y motivador.

---

## Line 1 — CROSSFIT · WOD (Frame 1)

    Mountain Climbers: en plancha, rodillas al pecho alternando rápido. Cardio y core a la vez.

## Line 2 — POSICIÓN INICIAL (Frame 2)

    Armá una plancha alta con las manos bajo los hombros y los pies cómodos.

## Line 3 — PASO 1 / 3 (Frame 3)

    Paso uno. Llevá una rodilla al pecho sin levantar la cadera ni perder la línea.

## Line 4 — PASO 2 / 3 (Frame 4)

    Paso dos. Cambiá de pierna alternando rápido, con ritmo parejo y constante.

## Line 5 — PASO 3 / 3 (Frame 5)

    Paso tres. Si la cadera se levanta y rebota, el core se apaga y el ritmo se rompe.

## Line 6 — CLAVES (Frame 6)

    Claves: cadera baja, manos bajo los hombros, ritmo parejo y core activo.

## Line 7 — A ENTRENAR (Frame 7)

    Treinta segundos, tres rondas. Descansá treinta entre rondas.
