# SCRIPT — plank-shoulder-taps

**Voice:** es_AR-daniela-high (piper, español rioplatense)
**Voice direction:** Coach claro y motivador.

---

## Line 1 — CROSSFIT · ACTIVACIÓN (Frame 1)

    Plank Shoulder Taps: tocar el hombro contrario sin mover la cadera. Core que no se mueve.

## Line 2 — POSICIÓN INICIAL (Frame 2)

    Plancha alta con las manos bajo los hombros y los pies un poco separados para estabilizar.

## Line 3 — PASO 1 / 3 (Frame 3)

    Paso uno. Levantá una mano y tocá el hombro del otro lado, sin apuro.

## Line 4 — PASO 2 / 3 (Frame 4)

    Paso dos. Volvé a apoyar y repetí con la otra mano, alternando.

## Line 5 — PASO 3 / 3 (Frame 5)

    Paso tres. Si la cadera se hamaca o se hunde, el core dejó de trabajar.

## Line 6 — CLAVES (Frame 6)

    Claves: cadera quieta, manos bajo los hombros, core activo y ritmo parejo.

## Line 7 — A ENTRENAR (Frame 7)

    Cuarenta segundos, dos series. Cambiá de mano cada dos o tres toques.
